# Freelance Science Writer Portfolio

A modern, minimalist, and perfectly responsive portfolio website for a Freelance Science Writer, crafted with clean semantic HTML, modular CSS (with robust Dark Mode support), and vanilla JavaScript.

## Features
- **Editorial Design System**: Typography-driven design using *Merriweather* and *Inter*, mimicking premium science journals.
- **Two-Color Brand Palette**: Intelligent deep slate combined with a vibrant bioluminescent teal accent. No clutter.
- **Robust Responsiveness**: Engineered for flawless visual cadence across mobile, tablet, and ultra-wide desktops.
- **Light & Dark Mode**: Built-in, zero-dependency theme toggle leveraging CSS Custom Properties and `localStorage` memory.
- **Zero-Dependency Core**: Lightweight structure relying exclusively on Vanilla HTML/CSS/JS (with CDN-linked Lucide icons) for maximum performance and SEO.

## Directory Structure
Follows an organized asset pipeline pattern:
```
├── assets/
│ ├── css/         (style.css, dark-mode.css, rtl.css)
│ ├── js/          (main.js, plugins/)
│ ├── images/
│ └── fonts/
├── pages/         (index, about, articles, publications, blog, contact)
├── documentation/
└── README.md
```

## Setup & Deployment
1. Simply clone or download this repository.
2. Ensure you optionally run a local web server (e.g., `npx serve` or Live Server extension in VS Code) to accurately preview relative linking and module fetching (if later extended).
3. Begin navigation from `pages/index.html`.

## Browser Support
Fully optimized for all evergreen modern web browsers: Chrome, Firefox, Safari, Edge.
